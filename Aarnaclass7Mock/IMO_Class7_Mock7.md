## Detailed Solutions

**Q1.** Differences are 3, 5, 7, 9, next is 11 → 27 + 11 = **38**. (B)

**Q2.** Each letter of BDFH is shifted +7: B+7=I, D+7=K, F+7=M, H+7=O → IKMO. Apply +7 to PRTV: P+7=W, R+7=Y, T+7=A, V+7=C → **WYAC**. (A)

**Q3.** FROG → HTQI uses +2, +2, +2, +2. Apply +2 to BIRD: B→D, I→K, R→T, D→F → **DKTF**. (A)

**Q4.** "good" is common to 351 & 436 → common digit 3, so good=3. "sweet" is common to 351 & 425 → common digit 5, so sweet=5. "flower" is common to 425 & 436 → common digit is **4**, so flower=4. (B)

**Q5.** Grandfather's only daughter = Meera's mother. Her son = Meera's **brother**. (A)

**Q6.** North 4, right (East) 3, right (South) 4. Net vertical displacement = 0, horizontal = 3 km East. Distance = **3 km**. (A)

**Q7.** Order left-to-right: Amit, Rohan, Priya, Kabir, Sohan. Middle (3rd) = **Priya**. (B)

**Q8.** Rank from bottom = (40 − 12) + 1 = **29th**. (B)

**Q9.** Pattern: value = (2n)² = squares of even numbers: 1→2²=4, 2→4²=16, 3→6²=36, 4→8²=64, so 5→10²=**100**. (B)

**Q10.** Letter **A** is symmetric about a vertical axis, so it looks the same in a vertical mirror. (C)

**Q11.** The mid-segment splits the triangle into a small top triangle and a trapezium; the median further subdivides. Counting all triangles formed gives **8**. (C)

**Q12.** Folding top-to-bottom and cutting at the fold produces a single symmetric cut-out straddling the fold line → **1** hole. (A)

**Q13.** 8=2³, 27=3³, 64=4³, 125=5³ are perfect cubes; 100 is not. Odd one = **100**. (C)

**Q14.** C+A+B = 3+1+2 = **6**. (B)

**Q15.** Series of prime numbers; after 13 comes **17**. (C)

**Q16.** −15+24=9; −9+6=−3; 9+(−3) = **6**. (A)

**Q17.** (−8)(−5)=40; (−3)(4)=−12; 40+(−12)=**28**. (A)

**Q18.** LCM 12: 9/12 + 10/12 − 6/12 = 13/12. (A)

**Q19.** 2.5 × 0.04 = 0.10 = **0.1**. (A)

**Q20.** Values: −2/3≈−0.667, −3/4=−0.75, −1/2=−0.5, −5/6≈−0.833. Greatest (closest to 0) = **−1/2**. (C)

**Q21.** 5x−2x = 8+7 → 3x=15 → x=**5**. (B)

**Q22.** x + 3x = 180 → 4x=180 → x=45°. Smaller = **45°**. (B)

**Q23.** Third angle = 180−(55+65)=60°. Exterior angle = 180−60 = **120°** (equals sum of the two remote interior angles 55+65). (B)

**Q24.** RHS = Right angle, Hypotenuse, Side. (B)

**Q25.** Discount = 15% of 800 = 120; SP = 800−120 = **₹680**. (A)

**Q26.** (4x−2x) + (3y+5y) = **2x + 8y**. (A)

**Q27.** 2^(3+4−2) = 2⁵. (A)

**Q28.** Side = 48/4 = 12 cm; area = 12² = **144 cm²**. (A)

**Q29.** ½ × 12 × 9 = **54 cm²**. (B)

**Q30.** 4 appears three times → mode = **4**. (A)

**Q31.** Multiples: 3,6,9,12,15; sum=45; mean=45/5 = **9**. (B)

**Q32.** A regular pentagon has **5** lines of symmetry. (C)

**Q33.** Triangular prism: **5 faces, 9 edges, 6 vertices**. (A)

**Q34.** (−3)²=9; (−2)³=−8; 9×(−8)=**−72**. (B)

**Q35.** C = 2πr = 2 × 22/7 × 7 = **44 cm**. (B)

**Q36.** 3×120 + 2×40 = 360 + 80 = **₹440**. (B)

**Q37.** 3/5 × 250 = **150 L**. (C)

**Q38.** 350 ÷ 25 = **14** days. (C)

**Q39.** Speed = 240/4 = 60 km/h; 60×7 = **420 km**. (B)

**Q40.** −4 + 11 = **7°C**. (A)

**Q41.** Profit = 1440−1200 = 240; % = 240/1200 ×100 = **20%**. (B)

**Q42.** Perimeter = 2(15+8) = 2×23 = **46 m**. (B)

**Q43.** Boys = 60% of 45 = 27; girls = 45−27 = **18**. (A)

**Q44.** 75 × 8 = **₹600**. (B)

**Q45.** 2/3 × 6 = **4 cups**. (B)

**Q46.** MP = 500 + 40% = 700; discount 10% → SP = 700 − 70 = 630; profit = 630−500 = 130; % = 130/500 ×100 = **26%**. (B)

**Q47.** Even integers: n, n+2, n+4; sum = 3n+6 = 84 → n=26. Integers 26, 28, 30; smallest×largest = 26×30 = **780**. (A)

**Q48.** Outer area = 40×30 = 1200 m². Inner rectangle = (40−4)×(30−4) = 36×26 = 936 m². Path = 1200−936 = **264 m²**. (B)

**Q49.** (2/3)x − (1/2)x = 18 → (4x−3x)/6 = 18 → x/6 = 18 → x = **108**. (B)

**Q50.** Let angle B = b. Then A = 2b and C = b+30. Sum: 2b + b + (b+30) = 180 → 4b + 30 = 180 → 4b = 150 → b = 37.5°. So A = 75°, B = 37.5°, C = 67.5°. Largest angle = A = **75°**. (B)
